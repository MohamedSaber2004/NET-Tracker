Track Every Request.
Zero Latency.

The high-performance HTTP tracking library for ASP.NET Core 8.0. Built for developers who refuse to sacrifice speed for observability.

Get Started dotnet add package NET-Tracker

Architectural Isolation

Powered by System.Threading.Channels. Logging runs in a dedicated background pipe, ensuring your HTTP pipeline remains 100% non-blocking.

Circuit Breaker Protection

If your database fails, NET-Tracker detaches automatically. Your main application stays healthy while it retries in the background.

Auto PII Masking

Zero-config protection. Automatically identifies and masks passwords, tokens, and secrets in JSON bodies before they ever hit the disk.

Setup in 60 Seconds

Program.cs
// Add the tracking services
builder.Services.AddHttpTracker(options => {
    options.StorageType = "SqlServer";
    options.LogSensitiveData = false;
});

// Enable the middleware
app.UseHttpTracker();
